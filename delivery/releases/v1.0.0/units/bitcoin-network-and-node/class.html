บิตคอยน์คือเครือข่ายของโหนดจำนวนมาก

คอมพิวเตอร์ที่รันซอฟต์แวร์บิตคอยน์เรียกว่าโหนด (node) เชื่อมต่อกันเป็นโครงข่าย (mesh network) พวกมันเชื่อมต่อแลกเปลี่ยนข้อมูลถึงกันแต่ไม่เชื่อใจกัน แต่ละโหนดตรวจสอบข้อมูลที่ได้รับจากโหนดอื่นอย่างเข้มงวด

การรันโหนดใช้ทรัพยากรไม่มาก
ใครก็สามารถรันโหนดได้
เครือข่ายจึงกระจายศูนย์
จะฆ่าบิตคอยน์ให้ตายสนิทต้องทำลายโหนดทิ้งทั้งหมด
image placeholder
ทำให้คำว่า node ไม่ลอยเป็นศัพท์เทคนิค แต่เห็นเป็นภาพของคอมพิวเตอร์จริงในเครือข่ายจริง
ภาพคอมพิวเตอร์หรือเครื่องหลายชนิดกระจายอยู่ในหลายบริบท เช่น บ้าน โต๊ะทำงาน ห้องเซิร์ฟเวอร์ขนาดเล็ก หรืออุปกรณ์ปลายทาง แล้วมีเส้นเชื่อมอย่างนุ่มนวลเป็นเครือข่ายเดียวกัน ภาพควรสื่อความหลากหลายของผู้เข้าร่วมแต่ยังอยู่ภายใต้ระบบเดียว โดยจัดองค์ประกอบให้อยู่กึ่งกลางภาพและไม่ชิดขอบ เพื่อรองรับการครอปลงกรอบ placeholder

ทำให้ผู้เรียนเห็นว่างานของ node ไม่ได้มีมิติเดียว แต่เป็นทั้งการเก็บ ตรวจ และเผยแพร่ข้อมูลพร้อมกัน
ภาพกึ่งนามธรรมที่มี node หลักอยู่ตรงกลาง และมีสามมิติของการทำงานล้อมอยู่ เช่น ชั้นเอกสารหรือสมุดบัญชีแทนการเก็บข้อมูล ตราประทับหรือกลไกตรวจสอบแทนการตรวจตามกฎ และเส้นสัญญาณหรือแพ็กเก็ตข้อมูลที่วิ่งออกไปยังเครื่องอื่นแทนการกระจายข้อมูล ควรออกแบบให้รวมเป็นก้อนภาพเดียวตรงกลางเพื่อรองรับ placeholder mode

โหนดทำอะไรบ้าง

หน้าที่หลักของโหนดคือการเก็บรักษาบัญชีของบิตคอยน์ที่เรียกว่าบล็อกเชน (blockchain) และส่งต่อข้อมูลต่างๆ ระหว่างกัน

เก็บรักษาและอัปเดทบัญชีบล็อกเชน
ส่งข้อมูลธุรกรรมและบล็อกระหว่างกัน
ตรวจสอบข้อมูลว่าถูกต้องตามกฎหรือไม่
บริการข้อมูลให้กับแอปพลิเคชันอื่นๆ
การรันโหนดไม่มีค่าคอบแทน

และถูกตัดขาดออกจากเครือข่ายเดิม
