ภาพกึ่งอินโฟกราฟิกเชิงวัตถุที่มี block ใหม่อยู่ตรงกลาง แล้วรางวัลถูกแยกเป็นสองกระแสอย่างชัดเจน ฝั่งหนึ่งเป็นเหรียญใหม่ที่ระบบปล่อยออกมา อีกฝั่งเป็นค่าธรรมเนียมที่ไหลมาจากธุรกรรมของผู้ใช้ ควรสื่อว่าทั้งสองส่วนมารวมกันเป็นรางวัลก้อนเดียว

รางวัลของนักขุด (block reward) มีสองส่วน

ส่วนหนึ่งคือเหรียญใหม่ที่นักขุดสร้างให้ตัวเองได้ตามจำนวนที่กฎกำหนดไว้ (block subsidy) และอีกส่วนคือค่าธรรมเนียมธุรกรรม (transaction fee)

ไม่มีอัตราค่าธรรมเนียมที่ตายตัว แต่นักขุดมักเลือกธุรกรรมที่จ่ายค่าธรรมเนียมสูงใส่บล็อกก่อนเสมอ

แต่ละบล็อกมีผู้ได้รางวัลเพียงหนึ่งเดียว แต่นักขุดมักรวมตัวแบ่งปันผลประโยชน์กันเพื่อให้มีรายได้สม่ำเสมอ เรียกว่า mining pool
