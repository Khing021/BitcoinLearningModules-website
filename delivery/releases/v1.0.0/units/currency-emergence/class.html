สกุลเงิน (currency)

เกิดจากการพยายามสร้างมาตรฐาน
ให้กับโลหะมีค่าที่ถูกใช้เป็นเงิน

ปัญหาของโลหะมีค่าคือแต่ละก้อนหนักไม่เท่ากัน บริสุทธิ์ไม่เท่ากัน และต้องตรวจสอบทุกครั้งก่อนแลกเปลี่ยน แต่ละธุรกรรมต้องใช้เวลามาก การค้าขายขาดประสิทธิภาพ

ต้องชั่ง
ต้องตรวจสอบ
ยังไม่สะดวกพอ
ภาพโต๊ะแลกเปลี่ยนโลหะหลายก้อนที่ยังไม่มีมาตรฐาน ต้องคอยชั่งและตรวจสอบก่อนรับ
ทำให้ผู้เรียนเห็นว่าปัญหาตั้งต้นไม่ได้อยู่ที่โลหะไร้ค่า แต่อยู่ที่การใช้งานร่วมกันยังไม่มีมาตรฐาน
ภาพโต๊ะแลกเปลี่ยนที่มีโลหะหลายก้อนรูปร่างไม่สม่ำเสมอ วางกระจัดกระจายพร้อมเครื่องชั่งมือและรอยขูดตรวจเนื้อโลหะ ให้เห็นชัดว่าก่อนจะรับกันได้ ผู้คนต้องเสียเวลาชั่งและตรวจสอบทุกครั้ง

ภาพเหรียญชื่อเดิมแต่เนื้อในต่างกัน เหรียญหนึ่งมีโลหะมีค่าสูงกว่า อีกเหรียญถูกผสมโลหะราคาถูก
ทำให้ผู้เรียนเข้าใจกลไก debasement ทันทีโดยไม่ต้องพึ่งคำอธิบายยาว
ภาพเปรียบเทียบเหรียญสองเหรียญที่หน้าตา ชื่อหน่วย และตราประทับเหมือนกัน แต่เหรียญหนึ่งตัดให้เห็นเนื้อโลหะมีค่าสูง อีกเหรียญตัดให้เห็นเนื้อผสมโลหะราคาถูกมากขึ้น ควรสื่อว่าความต่างซ่อนอยู่ข้างใน

เวลาผ่านไป เหรียญยังชื่อเดิม
แต่คุณภาพอาจไม่เท่าเดิม

เมื่อรัฐควบคุมมาตรฐานได้ รัฐก็สามารถลดสัดส่วนโลหะมีค่าในเหรียญลง แต่ยังปล่อยเหรียญออกมาภายใต้ชื่อหน่วยเดิมได้

เมื่อรัฐต้องการใช้เงินแต่ไม่อยากเก็บภาษีเพิ่ม พวกเขาเอาเหรียญที่หมุนเวียนกลับมาไปหลอม เติมโลหะราคาถูกเข้าไป แล้วขึ้นรูปเป็นเหรียญหน้าตาแบบเดิม สัดส่วนโลหะมีค่าอย่างทองคำหรือเงินในแต่ละเหรียญลดลง และเหรียญที่หมุนเวียนในระบบก็มีจำนวนมากขึ้น

เมื่อสิ่งใดมีจำนวนมากขึ้น สิ่งนั้นก็มีค่าน้อยลง
แต่ละเหรียญจึงซื้อของได้น้อยลงเมื่อเวลาผ่านไป
กระบวนการนี้เรียกว่า Debasement
