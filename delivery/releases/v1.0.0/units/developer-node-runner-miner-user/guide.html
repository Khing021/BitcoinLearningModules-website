Narrative Role

นี่คือหน้าสรุปสำคัญของยูนิต 24 เพราะมันเชื่อมคนหลายกลุ่มเข้ากับแนวคิด decentralization ในเชิงอำนาจ

Purpose

ทำให้ผู้เรียนเห็นว่าคำว่าไร้ศูนย์กลางไม่ได้หมายถึงไม่มีมนุษย์อยู่ในระบบ แต่หมายถึงไม่มีใครสั่งทุกอย่างได้ฝ่ายเดียว

Speaker Notes

developer เขียน software ได้ แต่บังคับให้ทุกคนใช้ไม่ได้ node runner ถือกฎ miner ปกป้องระบบ และ user ทำให้ระบบมีมูลค่าทางเศรษฐกิจจริง

Bitcoin จึงไม่อยู่ได้เพราะคนกลุ่มเดียว แต่มันอยู่ได้เพราะหลายกลุ่มคานอำนาจและพึ่งพากันอยู่ในระบบเดียวกัน
