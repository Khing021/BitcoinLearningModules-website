รับบิตคอยน์ไม่ผิดกฎหมาย

กฎหมายไทยไม่ได้มองบิตคอยน์เป็นเงินแต่เป็นสินทรัพย์ประเภทหนึ่ง

การแลกบิตคอยน์กับสินค้าหรือบริการสามารถทำได้หากทั้งสองฝ่าย

สมัครใจ และได้รับความคุ้มครองตามกฎหมาย

เป็นธุรกรรมประเภทการแลกเปลี่ยน ไม่ใช่การซื้อขาย
