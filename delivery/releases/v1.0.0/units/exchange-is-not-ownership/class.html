ทำให้ผู้เรียนเห็นว่าเรื่องนี้เป็น tradeoff ระหว่าง convenience กับ control ไม่ใช่ศีลธรรมขาวดำ
ภาพเปรียบเทียบแบบซ้าย-ขวา เว้นพื้นที่กลาง 50% ให้ข้อความ ฝั่งซ้ายสื่อโลกของ custodial convenience เช่นระบบรับฝากที่เป็นระเบียบและมีคนจัดการให้ ฝั่งขวาสื่อโลกของ self-custody เช่นการเก็บกุญแจหรือ seed อย่างรอบคอบด้วยตัวเอง ทั้งสองฝั่งต้องอยู่ใน safe zone ของตัวเอง ไม่ล้ำเข้าพื้นที่ข้อความกลาง
