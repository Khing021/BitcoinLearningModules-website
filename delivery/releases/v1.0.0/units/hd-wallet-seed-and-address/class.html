แตกแขนงได้มากมาย

ทุกวันนี้เราไม่ได้ใช้ public key ในการรับเหรียญ แต่เปลี่ยนไปใช้ address ซึ่งคำนวณมาจาก public key อีกทีซึ่งมีความปลอดภัยมากกว่า

address เป็นของใช้ครั้งเดียวทิ้ง เราไม่ควรใช้ address เดิมรับเงินซ้ำๆ และ wallet สมัยใหม่สามารถสร้างชุด key และ address ใหม่ให้เราได้เรื่อยๆ มาตรฐานนี้เรียกว่า Hierarchical Deterministic wallet (HD wallet)

ควรสร้าง address ใหม่ทุกครั้งที่รับเงินเพื่อความปลอดภัยและความเป็นส่วนตัว

สำคัญที่สุดคือ
seed phrase

ทุกวันนี้แทนที่เราจะสุ่ม private key ทีละตัวทุกครั้งที่เราอยากได้ address ใหม่ เราใช้การสุ่ม seed phrase ชุดเดียวแล้วค่อยคำนวณหา private key, public key และ address ทั้งหมดของเราจาก seed phrase ตั้งต้นนั้น

seed phrase มีลักษณะเป็นคำศัพท์ภาษาอังกฤษ 12-24 คำ
ถ้า seed phrase ยังอยู่ ก็จะกู้ key ทั้งหมดของเราได้เสมอ
