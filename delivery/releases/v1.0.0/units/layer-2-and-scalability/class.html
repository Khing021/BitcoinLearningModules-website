Bitcoin ถูกออกแบบให้ช้าโดยตั้งใจ ไม่ใช่เงินที่จะใช้ซื้อของในชีวิตประจำวัน

แนวคิด "blockchain trilemma" อธิบายว่ามี 3 คุณสมบัติที่บล็อกเชนพยายามทำให้ดีพร้อมกัน แต่ต้องเลือกแค่ 2 อย่าง สิ่งที่ Bitcoin ขาดไปคือ scalability

✅ security: ความปลอดภัย
✅ decentralization: ความกระจายศูนย์
❌ scalability: ความสามารถในการรองรับธุรกรรมจำนวนมาก

ทำให้ผู้เรียนเห็นว่าโลก L2 แตกแขนงตาม design goal ของแต่ละแนวทาง
ภาพพื้นหลังแบบครึ่งล่างเหมือน u33p2: ครึ่งบนต้องโล่ง สว่าง และสะอาดสำหรับข้อความสามคอลัมน์ ส่วนครึ่งล่างค่อยมีองค์ประกอบภาพสามกลุ่มที่สื่อถึง design goals ของ L2 ได้แก่ การจ่ายเงินที่รวดเร็ว, การใช้งานแบบชุมชน/eCash/UX ที่ง่ายขึ้น, และชั้น settlement/asset layer โดยแต่ละกลุ่มล้อกับคอลัมน์ด้านบนของตัวเองอย่างชัดเจน

Bitcoin เลือกปรับปรุง scalability โดยพัฒนาเป็น layer2 ซึ่งปัจจุบันมีหลายตัว และมีจุดเด่นแตกต่างกันไป

เน้นการจ่ายเงินแบบไร้ตัวกลาง: Lightning

ใช้จ่ายเงินจำนวนน้อยๆ ได้รวดเร็วขึ้นและแทบไม่มีค่าธรรมเนียม โดยแทบไม่ต้องเชื่อใจใครเลยถ้าใช้งานอย่างถูกต้อง

เน้นความง่ายในการ self custody: Spark

พึ่งพาตัวกลางมากขึ้น แต่ยังไม่ถึงกับฝากเงินไว้กับเขา ใช้งานง่าย แต่ความเป็นส่วนตัวน้อยกว่า

เน้นความเป็นชุมชน:
Fedimint, Cashu, Ark

ลดความซับซ้อนเพื่อให้ผู้ใช้หน้าใหม่เริ่มต้นได้ง่าย ใช้ในระบบนิเวศของชุมชน และมีความเป็นส่วนตัว
