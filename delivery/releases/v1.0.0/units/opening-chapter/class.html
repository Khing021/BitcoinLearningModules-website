เงินคืออะไร

ทำไมสังคมมนุษย์ต้องใช้เงิน และเหตุผลที่เราต้องเข้าใจเงินก่อนจะเข้าใจ Bitcoin

เราต้องการสิ่งต่างๆ มากมายในชีวิต ถ้าเราไม่ใช้เงินกัน เราจะจัดหาทุกสิ่งทุกอย่างนี้ได้อย่างไร
