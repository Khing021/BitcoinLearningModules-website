กระดาษมีค่าได้เพราะคำสัญญาว่ามีทองรองรับจริง
paper claims stay valuable only while reserves can honor them

Narrative Role

เปิด Unit 8 ด้วยคำถามเชิงเงื่อนไข ให้ผู้เรียนหยุดมองกระดาษเป็นของสะดวกอย่างเดียว แล้วมองกลับไปที่ฐานสัญญาที่รองรับมันอยู่

Purpose

ย้ำว่าตั๋วกระดาษไม่มีค่าในตัวเอง แต่ได้ค่ามาจากสิทธิแลกทองคืน

วางฐานเหตุผลก่อนจะพาไปถึง bank run และการรวมศูนย์ในหน้าถัดไป

Speaker Notes

ตั๋วกระดาษไม่ได้มีค่าเพราะตัวกระดาษ แต่มีค่าเพราะคำสัญญาจากร้านรับแลกทองว่ากระดาษใบนี้สามารถแลกคืนเป็นทองจริงได้

นั่นหมายความว่า ร้านรับทองมาจากลูกค้าเท่าไร ก็ควรออกตั๋วได้ไม่เกินจำนวนนั้น และคนที่ถือตั๋วควรมีสิทธิแลกทองคืนเต็มจำนวนได้เสมอ

หน้านี้จึงทำหน้าที่ตั้งคำถามว่า แล้วถ้าร้านไม่รักษาสัญญานี้ล่ะ จะเกิดอะไรขึ้นกับทั้งระบบ

bank run คือวิกฤติที่ความเชื่อพังเร็วกว่าเวลาที่ระบบจะรับมือได้
early redeemers recover gold while late redeemers are left with worthless claims

Narrative Role

หน้านี้ต้องเปลี่ยนปัญหาเชิงบัญชีให้กลายเป็นภาพมนุษย์ที่ผู้เรียนรู้สึกได้ ว่าความต่างของการมาถึงก่อนหรือหลังสามารถตัดสินชะตาคนถือกระดาษได้เลย

Purpose

ทำให้ผู้เรียนเข้าใจความหมายของ bank run แบบเป็นรูปธรรม

สร้างแรงผลักทางเหตุผลสำหรับคำถามถัดไปว่า สังคมจะทำอย่างไรกับระบบที่เปราะบางแบบนี้

Speaker Notes

ถ้าร้านแลกทองออกตั๋วเกินกว่าทองที่มีจริง ระบบจะยังดูปกติดีอยู่ตราบใดที่คนส่วนมากยังไม่กลับมาไถ่ทองพร้อมกัน

แต่พอมีข่าวลือหรือความไม่มั่นใจเกิดขึ้น ผู้คนจะรีบนำกระดาษมาแลกทองคืนทันที และตรงนี้เองที่เราเห็นภาพของ bank run

คนที่มาถึงก่อนอาจยังได้ทองกลับไป แต่คนที่มาถึงช้าจะพบว่ากระดาษในมือแทบไม่มีค่าแล้ว และความเสียหายก็ไม่ได้หยุดอยู่แค่ร้านเดียว แต่อาจลามเป็นปัญหาของทั้งระบบ

ธนาคารกลางค่อย ๆ เกิดจากการรวมศูนย์บทบาทของระบบรับแลกทอง
state-backed centralization of reserves, note issuance, and settlement

Narrative Role

นี่คือสไลด์สะพานจากวิกฤติของร้านรับแลกทองเอกชน ไปสู่การเกิดสถาบันศูนย์กลางในภาพรวม ก่อนจะไปดูกรณีเฉพาะอย่างสหรัฐฯ ใน unit ถัดไป

Purpose

อธิบายว่ารัฐตอบสนองต่อความเปราะบางของระบบรับแลกทองด้วยการรวมศูนย์อำนาจมากขึ้นอย่างไร

ทำให้ผู้เรียนเห็นว่า central bank คือผลลัพธ์ของการรวมศูนย์บทบาทสำคัญของระบบเงิน ไม่ใช่แค่ชื่อสถาบันหนึ่งที่โผล่มาเฉย ๆ

Speaker Notes

เมื่อวิกฤติแบบนี้เกิดซ้ำ และผลเสียเริ่มกระทบผู้คนจำนวนมาก รัฐในหลายสังคมก็ไม่ได้ปล่อยให้กิจการรับแลกทองเอกชนกระจัดกระจายทำงานกันเองต่อไป

บางแห่งรัฐเข้ามากำกับเข้มขึ้น บางแห่งออกใบอนุญาต บางแห่งให้สถาบันที่ใกล้รัฐที่สุดทำหน้าที่รับฝาก ออกใบรับฝาก และเป็นศูนย์กลางการชำระหนี้เสียเอง

พูดอีกแบบคือ บทบาทที่เคยกระจายอยู่หลายร้านค่อย ๆ ถูกรวมเข้าหาศูนย์กลางมากขึ้น และนี่คือจุดตั้งต้นของสิ่งที่ภายหลังพัฒนาไปเป็นธนาคารกลาง

bank run ดับลงได้ เพราะศูนย์กลางมีอำนาจเปลี่ยนกติกา
inflation and suspended redemption replace the old market test of honesty

Narrative Role

นี่คือหน้าที่ปิด Unit 8 ให้ครบ ว่าการรวมศูนย์ไม่ได้แค่ลดความวุ่นวาย แต่ยังมอบอำนาจให้ศูนย์กลางสามารถพิมพ์เกินสำรองและระงับการทดสอบระบบได้ด้วย

Purpose

เชื่อมจาก bank run ไปสู่ inflation อย่างเป็นเหตุเป็นผล

ทำให้ผู้เรียนเห็นว่าปัญหาเดิมไม่ได้หายไป แต่ถูกจัดการด้วยอำนาจของศูนย์กลาง

Speaker Notes

แต่ถ้าผู้พิมพ์ตั๋วเกินทองสำรองกลายเป็นธนาคารกลางเอง เรื่องก็จะไปอีกแบบหนึ่ง

เมื่อธนาคารกลางพิมพ์ธนบัตรออกมาเกินทองสำรอง ปริมาณเงินในระบบก็เพิ่มขึ้น และเงินแต่ละหน่วยก็มีแนวโน้มใช้ซื้อของได้น้อยลง สิ่งนี้คือ inflation

ส่วนถ้าประชาชนแห่มาแลกทองคืน ศูนย์กลางก็สามารถระงับการแลกชั่วคราว หรือเปลี่ยนเงื่อนไขการแลกได้ ทำให้ปัญหา bank run แบบเดิมดูเหมือนหายไป เพราะประตูทดสอบระบบถูกควบคุมจากส่วนกลางแล้ว
