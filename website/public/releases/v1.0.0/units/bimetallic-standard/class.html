ภาพทองคำสำหรับธุรกรรมมูลค่าสูงคู่กับเหรียญเงินสำหรับการจับจ่ายรายวัน
ทำให้ผู้เรียนเห็นว่าทองคำไม่ได้แพ้ แต่บทบาทของมันไม่เหมาะกับทุกขนาดธุรกรรม
ภาพสองบริบทในสังคมเดียวกัน ฝั่งหนึ่งเป็นการชำระมูลค่าสูงที่ใช้ทองคำ อีกฝั่งเป็นตลาดประจำวันหรือการซื้อของชิ้นเล็กที่ใช้เหรียญเงินหรือโลหะมูลค่าต่ำกว่า ควรสื่อว่าปัญหาคือ scale ของมูลค่า

ทองคำมีมูลค่าสูงมากเมื่อเทียบกับขนาดและน้ำหนัก

ทองคำชิ้นเล็กๆ ก็ซื้อของได้มากมาย การแบ่งเป็นเศษย่อยๆ

เพื่อซื้อของจำนวนน้อยจึงเป็นเรื่องยาก ดังนั้นจึงจำเป็นต้องใช้

โลหะชนิดอื่นที่มีมูลค่าน้อยกว่าเข้ามาเสริมสำหรับ

ภาพระบบเงินหลายระดับในสังคมเดียวกัน ตั้งแต่มูลค่าสูงจนถึงหน่วยย่อยรายวัน
สื่อว่าโลกแต่ละพื้นที่อาจเลือกวัสดุต่างกัน แต่หลักคิดร่วมคือสร้างระบบเงินที่ครอบคลุมหลายระดับของธุรกรรม
ภาพระบบเงินหลายระดับในสังคมเดียวกัน อาจมีหน่วยมูลค่าสูงอยู่ด้านหนึ่ง หน่วยรายวันอยู่ตรงกลาง และหน่วยย่อยมากอย่างหอยเบี้ยหรือวัสดุอื่นอยู่ปลายภาพ ให้เห็นความต่อเนื่องของระดับมูลค่า ไม่ใช่แค่โชว์ของสะสม

โจทย์เดียวกัน แนวคิดเดียวกัน
แต่พื้นที่อื่น ก็ใช้วัสดุอื่น

ในพื้นที่อื่นอาจไม่ได้ใช้ทองคำและเงินคู่กัน อย่างในสยามเราใช้

แร่เงิน (พดด้วง) สำหรับมูลค่าขนาดใหญ่ คู่กับเปลือกหอย (เบี้ย)
