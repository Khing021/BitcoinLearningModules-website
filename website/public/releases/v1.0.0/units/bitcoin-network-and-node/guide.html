Bitcoin ไม่ได้มีสำนักงานใหญ่
system opener that breaks the central-server mental model

Narrative Role

เปิดบทด้วยการรื้อภาพจำเดิมว่าระบบดิจิทัลต้องมีเจ้าของหรือเซิร์ฟเวอร์กลางก้อนเดียว

Purpose

ทำให้ผู้เรียนพร้อมคิดแบบระบบเครือข่าย แทนการคิดแบบองค์กรที่มีหัวหน้าสั่งการจากด้านบน

Speaker Notes

เวลาคนได้ยินคำว่า Bitcoin ครั้งแรก หลายคนจะนึกถึงบริษัทสักแห่งหรือเซิร์ฟเวอร์ก้อนใหญ่สักก้อนที่คอยเก็บบัญชีให้ทุกคน

แต่บทนี้กำลังจะชี้ว่า Bitcoin ทำงานได้โดยไม่ต้องมีศูนย์กลางแบบนั้นเลย

Bitcoin คือเครือข่ายของ node จำนวนมาก
define node as the basic participating computer in the network

Narrative Role

นี่คือหน้าตั้งนิยามหลักของคำว่า node ซึ่งจะถูกใช้ต่อไปทั้งบท

Purpose

ทำให้ผู้เรียนเข้าใจว่าระบบนี้เริ่มจากคอมพิวเตอร์จำนวนมาก ไม่ใช่เริ่มจากเหรียญลอย ๆ

Speaker Notes

ถ้าจะพูดให้สั้นที่สุด Bitcoin คือเครือข่ายของคอมพิวเตอร์จำนวนมากที่รันซอฟต์แวร์ชุดเดียวกัน

และคอมพิวเตอร์ที่เข้าร่วมแบบนี้ เราเรียกว่า node

node ทำหน้าที่อะไร
turn the definition of node into three concrete jobs

Narrative Role

หน้านี้ช่วยให้ node ไม่เป็นคำลอย ๆ เพราะผู้เรียนเริ่มเห็นว่างานของมันคืออะไรบ้าง

Purpose

ทำให้การพูดเรื่องเครือข่ายต่อจากนี้ง่ายขึ้น เพราะผู้เรียนเริ่มเห็นกลไกภายในของ node แล้ว

Speaker Notes

แต่ละ node เชื่อมต่อถึงกัน แลกข้อมูลถึงกัน และเก็บประวัติธุรกรรมของระบบเอาไว้

สิ่งที่คุมระบบไม่ใช่คน แต่คือกฎ
shared rules hold the network together; different rules can split it

Narrative Role

นี่คือสไลด์แกนของทั้งยูนิต เพราะมันอธิบายว่าความกระจายศูนย์ของ Bitcoin ยืนอยู่บนอะไร

Purpose

ทำให้ผู้เรียนเห็นว่า decentralization ไม่ได้แปลว่าไม่มีอะไรคุมเลย แต่แปลว่าถูกคุมด้วยกฎร่วมกันแทนหัวหน้า

Speaker Notes

ไม่มี node ไหนเป็นหัวหน้าของทั้งระบบ สิ่งที่ทำให้มันยังเป็นเครือข่ายเดียวกันได้ คือทุกคนยอมรับกฎชุดเดียวกัน

ถ้าใครใช้กฎไม่เหมือนคนอื่นมากพอ node นั้นก็อาจค่อย ๆ แยกตัวออกจากเครือข่ายหลัก
