ปิดยูนิตด้วยความเข้าใจว่าระบบนี้ไม่ได้ถูกคุมโดยบทบาทใดบทบาทหนึ่ง แต่ยืนอยู่บนความสัมพันธ์หลายด้าน
ภาพเชิงระบบแบบ center-safe ที่มีกลุ่มผู้เล่น 4 บทบาทวางอยู่รอบนอกเหมือนระบบนิเวศที่คานอำนาจและพึ่งพากัน โดยเว้นพื้นที่กลางไว้สำหรับข้อความหลัก ภาพควรสื่อความเชื่อมโยงและสมดุล ไม่ใช่การแข่งขันแบบมีผู้ชนะคนเดียว

สมดุลบนการคานอำนาจ

แต่ละบทบาทของผู้เล่นรักษาความสมดุลของระบบ

นักพัฒนา (developer): เสนอการพัฒนาใหม่ๆ

ผู้รันโหนด (node runner): เลือกนำข้อเสนอไปปฏิบัติ

นักขุด (miner): ปกป้องระบบด้วยพลังงาน

ผู้ใช้งาน (user): มอบความหมายและคุณค่าให้ระบบ

ข้อเสนอที่จะถูกนำไปใช้จริง ต้องเป็นประโยชน์กับทุกฝ่าย
แต่ละคนมีอิสระในการตัดสินใจ บังคับกันไม่ได้
ไม่ใช่ประชาธิปไตยเสียงข้างมาก แต่เป็นอนาธิปไตย
