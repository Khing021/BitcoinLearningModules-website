คุณสมบัติของเงินที่ดี

มนุษย์อาจหยิบสินค้าอะไรมาใช้เป็นเงินก็ได้
แต่สิ่งของบางอย่างมีคุณสมบัติที่ทำให้มันทำหน้าที่เป็นเงินได้ดีกว่าของชนิดอื่นๆ

durability
ทนทาน ไม่เน่า ไม่ผุ ไม่ขึ้นสนิม
portability
พกพาเคลื่อนย้ายได้สะดวก
fungibility
แต่ละหน่วยเหมือนๆ กัน ใช้แทนกันได้
scarcity
มีจำกัด ผลิตเพิ่มได้ยาก
acceptability
เป็นที่ยอมรับในวงกว้าง ใครก็อยากได้
divisibility
แบ่งหน่วยย่อยได้ รวมเป็นหน่วยใหญ่ได้
