รับ Bitcoin ไม่ยาก

แค่ส่ง address ของเราให้อีกฝ่าย

กดปุ่ม "recieve" หรือ "รับเงิน" บน wallet เพื่อสร้าง address สำหรับรับเหรียญ แล้วส่ง address นั้นให้กับคนที่จะส่ง Bitcoin มาให้เรา หรือกรอก address ของเราให้กับ exchange ในตอนที่เราจะสั่งถอนเหรียญ

หากทุกอย่างถูกต้อง วอลเล็ตของเราจะรับรู้ว่ามีเหรียญถูกส่งมา เมื่อธุรกรรมเปลี่ยนสถานะจาก "pending" เป็น "confirmed" เราจะมั่นใจได้ว่าธุรกรรมนั้นถูกบรรจุลงบล็อกเชนแล้ว จะไม่สามารถแก้ไขหรือเปลี่ยนแปลงได้อีก

ควรตรวจสอบ address จากบนหน้าจอ hardware wallet
ส่งมอบสินค้าหลังจากธุรกรรมมีสถานะ "confirmed"
