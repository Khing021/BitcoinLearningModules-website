บิตคอยน์ไม่ได้อยู่ในมือถือ/คอมพิวเตอร์

บิตคอยน์ของเราถูกล็อคไว้บนบล็อกเชน สิ่งที่อยู่ในอุปกรณ์ของเราจริงๆ คือคีย์ที่สามารถปลดล็อคเพื่อใช้งานบิตคอยน์นั้นได้

ทำ key หาย = ทำบิตคอยน์หาย
คนอื่นเอา key ไปได้ = เขาใช้บิตคอยน์ของเราได้

ภาพเชิงอธิบายที่ตัดความเข้าใจผิดว่ามือถือเก็บเหรียญไว้ข้างในจริง ๆ โดยแสดงมือถือเป็นเพียงเครื่องมือเข้าถึงสิทธิ์บนเครือข่ายที่อยู่ภายนอก จัดองค์ประกอบไว้กึ่งกลางและเผื่อ safe margin

และ public key

เราเป็นเจ้าของเหรียญดิจิทัล
ได้ด้วย key สองตัวนี้

ในยุคแรก เราเริ่มจากสุ่มตัวเลขยาวๆ ขึ้นมาตัวหนึ่ง ใช้มันเป็น

private key แล้วค่อยเอา private key ไปคำนวณเป็น public key

public key เปิดเผยให้คนอื่นรู้ได้ แต่ private key ต้องเก็บเป็นความลับ

มี private key คำนวณหา public key ได้
มี public key คำนวณย้อนหา private key ไม่ได้
public key ส่งให้คนอื่นเอาไว้ใช้ส่งเหรียญให้เรา
private key เก็บไว้กับตัว เอาไว้ใช้ปลดล็อคเหรียญ
