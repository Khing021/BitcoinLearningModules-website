ภาพแรงกดดันจากหลายประเทศที่พยายามแลกดอลลาร์กลับเป็นทองจากคลังกลาง จนทองสำรองดูไม่พอ
ทำให้ผู้เรียนเห็นว่าโจทย์เดิมเรื่อง reserve mismatch กลับมาอีกครั้ง แต่ยกระดับจากเอกชนไปสู่ระดับประเทศ
ภาพพื้นหลังเต็มสไลด์ที่สื่อแรงกดดันระดับโลกต่อคลังทองของสหรัฐฯ อาจเห็นคำขอแลกคืนดอลลาร์จากหลายประเทศพุ่งเข้าหาทองสำรองก้อนเดียว ให้บรรยากาศเหมือน bank run ข้ามชาติ

และแล้วสหรัฐฯ ก็ผิดสัญญา

ปี 1971 ประธานาธิบดีนิกสันประกาศ
ยกเลิกการให้แลกคืนดอลลาร์เป็นทองคำ

มาตรการนี้ถูกประกาศว่าเป็นมาตรการชั่วคราว แต่จนถึงปัจจุบัน (มากกว่า 50 ปี) ดอลลาร์ยังคงไม่สามารถแลกคืนเป็นทองคำจากรัฐบาลสหรัฐฯ ได้ ราคาทองคำลอยตัวออกจากค่าเงินดอลลาร์นับแต่นั้น

เหตุการณ์นี้เรียกว่า Nixon Shock
เงินไม่ได้ยึดโยงกับทองคำอีกต่อไป
มาตรฐานทองคำจบลงแล้ว
ภาพช่วงประกาศ Nixon Shock ที่สื่อการตัดความเชื่อมโยงระหว่างดอลลาร์กับทองคำ
ทำให้ผู้เรียนจำ 15 สิงหาคม 1971 เป็น moment ที่ระบบเงินหลุดจากทองอย่างมีนัยประวัติศาสตร์
ภาพกึ่งประวัติศาสตร์ของการประกาศ Nixon Shock หรือภาพเชิงสัญลักษณ์ที่สื่อการตัดสายเชื่อมระหว่างดอลลาร์กับทองคำอย่างเด็ดขาด ควรให้ความรู้สึกของการเปลี่ยนยุค ไม่ใช่แค่ประกาศข่าวทั่วไป
