มาตรฐานเงินเฟียต

เงินกระดาษที่หนุนหลังด้วยความน่าเชื่อถือของรัฐบาล

เงินเฟียต (fiat money) คือเงินที่รัฐผลิตและสั่งให้ประชาชนใช้งานด้วยอำนาจกฎหมาย ไม่มีโลหะมีค่าหนุนหลังอีกต่อไป

สกุลเงินประจำชาติต่างๆ ล้วนเป็นเงินเฟียต
นี่คือเงินที่เราใช้กันอยู่ในปัจจุบัน
ภาพการเปลี่ยนฐานของความเชื่อถือจากทองคำไปสู่เงินที่มีอำนาจรัฐรับรอง
ทำให้คำว่า fiat money มีภาพในหัว ไม่ใช่เป็นแค่นิยามศัพท์
ภาพช่วงเปลี่ยนผ่านเชิงนามธรรมแต่จับต้องได้ จากทองคำหรือฐานกายภาพ ไปสู่เอกสาร เงินสมัยใหม่ หรือสัญลักษณ์ของเงินที่มีอำนาจรัฐรับรอง โดยต้องสื่อว่าฐานของความเชื่อถือได้เปลี่ยนตัวกลางแล้ว

ภาพเงินในระบบขยายตัว ขณะที่ค่าครองชีพและราคาของใช้จำเป็นค่อย ๆ สูงขึ้น
ทำให้ความเชื่อมโยงระหว่าง money expansion กับค่าครองชีพสูงขึ้นดูเป็นเรื่องจริงในชีวิต ไม่ใช่แค่ทฤษฎี
ภาพพื้นหลังเต็มสไลด์ที่สื่อการขยายตัวของปริมาณเงินตัดกับกำลังซื้อที่ค่อย ๆ กัดกร่อนลง อาจใช้ภาพชีวิตประจำวันและราคาที่ขยับสูงขึ้นแทนการใช้กราฟล้วน เพื่อให้ผลกระทบดูใกล้ตัว

เมื่อไม่มีข้อจำกัดแบบเดิมคอยผูกไว้
ปริมาณเงินก็ขยายเพิ่มได้ง่ายมาก

ชีวิตยาก

ทุกคนสัมผัสได้ว่ามีบางอย่างผิดปกติ

ปัญหาเชิงโครงสร้างดูเหมือนจะมีอยู่ทุกที่ หลายคนเชื่อว่ามันคือเรื่องการเมือง แต่บางคนรู้ดีว่าปัญหามาจากเงินที่เราใช้

ชีวิตลูกหลานยากลำบากกว่าพ่อแม่
เด็กเกิดน้อย คนเลี้ยงลูกไม่ไหว
จะมีบ้านสักหลังก็ไกลเกินเอื้อม
แทบไม่มีหวังในการสร้างเนื้อสร้างตัว
ภาพคนธรรมดาที่พยายามสร้างชีวิตมั่นคง แต่เป้าหมายอย่างบ้านหรือครอบครัวดูไกลออกไปเรื่อย ๆ
ทำให้ผู้เรียนเชื่อมคำว่า fiat system เข้ากับประสบการณ์ชีวิตจริง ไม่ใช่เรื่องนโยบายที่อยู่ไกลตัว
ภาพชีวิตคนธรรมดาที่พยายามสร้างเสถียรภาพในชีวิต แต่รู้สึกว่าระยะห่างจากเป้าหมายเช่นบ้าน ครอบครัว หรือความมั่นคงกำลังถอยออกไป ควรเป็นภาพที่มี emotional weight แต่ไม่ melodramatic
