แต่ถ้าธนาคารกลางเองพิมพ์
ธนบัตรเกินทองสำรองล่ะ?

ในตอนนี้ถ้าประชาชนแห่แลกธนบัตรเป็นทอง ธนาคารกลางก็สามารถระงับการแลกชั่วคราว หรือประกาศลดปริมาณทองที่ให้แลกคืนลงได้ ปัญหา bank run หายไป แต่เงินของทุกคนเสื่อมค่าลงเรื่อยๆ

เมื่อมีวิกฤติ ธนาคารกลางก็พิมพ์เงินช่วยเหลือ
มีปริมาณเงินมากขึ้น เงินก็ซื้อของได้น้อยลง
ปรากฎการณ์นี้เรียกว่าเงินเฟ้อ (inflation)
และวิกฤติก็เกิดขึ้นอยู่เสมอๆ
ภาพธนาคารกลางที่พิมพ์ธนบัตรเกินทองสำรอง และมีอำนาจปิดหรือจำกัดการแลกทองคืนได้
ทำให้ผู้เรียนเห็นว่าปัญหา bank run ไม่ได้หายไปเพราะความเปราะบางหมดไป แต่เพราะศูนย์กลางมีอำนาจจะเปลี่ยนกติกาและผลักต้นทุนออกไปเป็นเงินเฟ้อ
ภาพเชิงสถาบันของธนาคารกลางที่มีธนบัตรไหลออกมามากกว่าทองสำรอง พร้อมนัยว่าประตูการแลกทองสามารถถูกปิดหรือจำกัดได้ ควรสื่อทั้ง inflation และอำนาจระงับการแลกคืนในภาพเดียว
